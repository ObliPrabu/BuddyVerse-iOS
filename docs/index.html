Under the hood

For anyone poking at the code.

Native SwiftUI

Scaffolded and ported from the Android Kotlin source directly, mirroring its architecture 1:1 where iOS conventions allow.

iOS 14.0+

Deployment target deliberately lowered to run on older, hardware-capped devices.

Shared Firebase backend

Same Firebase project as the Android app for real-time multiplayer, so players on either platform can play together.

xcodegen-managed project

project.yml is the source of truth for the Xcode project — no committed .xcodeproj.
